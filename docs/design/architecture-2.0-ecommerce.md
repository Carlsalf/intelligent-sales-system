# Intelligent Sales System
## Architecture 2.0 – E-commerce Sales Module

## Objetivo

Evolucionar Intelligent Sales System hacia una plataforma comercial inteligente con web administrativa y app móvil multiplataforma.

## Nueva visión del sistema

### Web administrativa
- Administración
- Dashboard
- Productos
- Clientes
- Ventas
- Usuarios
- Analítica
- Reportes

### App móvil multiplataforma
- Catálogo
- Carrito
- Pedido
- Pago simulado
- Seguimiento
- Historial

### Backend / motor de negocio
- Gestión de pedidos
- Reserva de stock
- Compromiso de abastecimiento
- Inventario
- Reportes
- Analítica

## Principio de negocio

Una venta nunca debe perderse por falta de stock.

Si el inventario disponible no cubre completamente un pedido, el sistema generará automáticamente un compromiso de abastecimiento, asignando una fecha estimada de entrega para mantener la venta activa.

## Flujo general

Cliente -> Catálogo -> Carrito -> Pedido -> Pago simulado -> Reserva/Compromiso -> Entrega -> Conformidad -> Reportes.
